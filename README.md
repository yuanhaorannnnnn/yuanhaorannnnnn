# Haoran Yuan

I build **agent infrastructure** and **simulation tooling for embodied AI**: small, inspectable systems with explicit contracts, reproducible experiments, and evidence-backed delivery.

## Selected work

- [**agent-skills**](https://github.com/yuanhaorannnnnn/agent-skills) — manifest-driven, contract-tested skills for Claude Code and Codex.
- [**carla-autoresearch**](https://github.com/yuanhaorannnnnn/carla-autoresearch) — an external experiment controller for repeatable CARLA LiDAR optimization loops.
- [**stroll**](https://github.com/yuanhaorannnnnn/stroll) — an AMap-powered life-assistant plugin for ChatGPT and Codex.

## What I care about

- Agent workflows with explicit trigger boundaries, verification gates, and recoverable artifacts.
- Autonomous-driving and robotics simulation where a benchmark result remains reproducible and interpretable.
- Developer tools that make the shortest useful path clear without hiding operational constraints.
